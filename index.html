About

업무 이해가
설계의 출발점입니다.

현재 시스템이 어떻게 쓰이는지, 사용자는 무엇을 필요로 하는지 파악하며 개발을 시작합니다.

2022년부터 엠로에서 삼성전자, 만도, S-OIL, kt cloud 등 고객사의 구매·SRM 프로젝트에 참여했습니다. 기존 시스템 분석과 사용자 요구사항 정리를 바탕으로 To-Be 시스템을 만드는 일을 해왔습니다.

업무 흐름을 화면과 기능으로 구체화하고, Java·Spring 기반 API와 데이터 연계까지 구현합니다. 업무를 이해하는 과정과 실제 동작하는 시스템을 만드는 과정을 함께 연결하는 것이 제 강점입니다.

시스템을 만드는 업무 흐름

현행 분석부터 To-Be 구현까지

  1. AS-IS

    현행 시스템 분석

    기존 업무가 화면과 데이터에 어떻게 연결되어 있는지 파악합니다.

  2. REQUIREMENTS

    사용자 요구사항 분석

    현업이 필요로 하는 기능과 개선할 업무 흐름을 정리합니다.

  3. TO-BE

    목표 시스템 설계

    분석한 내용을 바탕으로 새로운 화면, 기능, 데이터 흐름을 설계합니다.

  4. IMPLEMENTATION

    시스템 구현

    프론트엔드, 백엔드 API, DB 연계를 구현해 요구사항을 시스템으로 연결합니다.

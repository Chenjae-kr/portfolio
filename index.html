02 / 문제 해결

기술 문제 해결.

SQL 목록 조회 최적화 · Tomcat 엑셀 생성 장애 해결

SQL 성능 개선 · kt P&M공정내역서 목록 조회 성능 최적화약 10초 → 2초

일위대가·품목·단가 변경 여부를 목록에 표시하기 위해 여러 테이블을 결합하면서 조회 지연이 발생했습니다. 실행계획 분석을 바탕으로 JOIN을 EXISTS로 전환하고, 선필터링, 서브쿼리·집계 조정, 인덱스 활용을 개선했습니다.

결과: 약 10,000건 기준 검색 클릭부터 목록 표시까지 약 10초에서 2초로 감소했습니다. 당시 경험에 근거한 대략적인 측정값입니다.

WAS 장애 해결 · kt P&M특정 WAS의 엑셀 파일 생성 장애 해결정상 동작 복구

동일한 애플리케이션을 실행하는 두 WAS 중 한 서버에서만 XLSX 파일이 손상됐습니다. OS·JDK·Tomcat 환경을 비교하고 shared.loader 및 라이브러리 참조 설정 차이를 확인했습니다.

결과: 장애 서버의 shared.loader 설정을 비활성화한 후 파일 생성 및 열기 정상 동작을 확인했습니다. 원인 분석부터 설정 변경·검증까지 직접 수행했습니다.

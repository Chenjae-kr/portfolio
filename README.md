# 웹 개발자 포트폴리오 + 프로젝트 경력 정리

2026-11-22 기준으로 만든 포트폴리오 시안과 자기소개서·경력기술서 작성용 프로젝트 정리 파일입니다.

## 파일 안내

- `index.html` — 배포용 포트폴리오 메인 페이지
- `assets/style.css` — Wanted Sans, 흰색·검정·네이비 디자인, 반응형 스타일
- `assets/app.js` — 네비게이션, 스크롤 효과 등
- `preview.html` — CSS와 JavaScript가 포함된 단일 HTML 미리보기
- `docs/project-experience.md` — 10개 프로젝트 및 주요 기술 사례의 역할·구현·성과 상세 정리

## 확인 방법

1. 압축을 해제합니다.
2. `preview.html`을 웹 브라우저로 열어 화면을 확인합니다.
3. 실제 배포 시에는 `index.html`과 `assets/` 폴더를 함께 사용합니다.
4. 자기소개서 작성 시 `docs/project-experience.md`를 참고합니다.

## 유의사항

- 이 ZIP을 만든 시점에는 GitHub 저장소에 반영하지 않았습니다. 배포하려면 별도로 커밋해야 합니다.
- Wanted Sans는 외부 웹폰트를 사용하므로 인터넷이 연결되어야 해당 폰트가 적용됩니다.
- 성능 측정 수치는 기억에 따른 대략적인 수치입니다.
- 고객사 공개 가능 범위와 내부 정보 보안 정책을 확인한 뒤 공개 저장소에 올리세요.
